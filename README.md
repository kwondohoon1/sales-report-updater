# 매출현황 최신화

판매 내역·재고·가격세팅 엑셀을 넣으면 `매출현황_컴포넌트.xlsx` 워크북을 최신화해서 내려받게 해 주는 웹 도구입니다.

**파일은 브라우저 안에서만 처리됩니다.** 페이지는 정적 파일뿐이고 서버가 없습니다. CSP(`connect-src 'none'`)로 외부 통신 자체를 막아 두었습니다. 레포에는 코드만 있고, 엑셀·CSV는 `.gitignore`(허용 목록)와 pre-commit 훅으로 커밋이 막혀 있습니다.

## 쓰는 법

1. 페이지를 엽니다.
2. 파일 4종을 한꺼번에 끌어 놓습니다. 종류는 내용으로 알아서 구분합니다.

   | 종류 | 예 | 구분 기준 |
   |---|---|---|
   | 매출현황 (필수) | `261001_매출현황_컴포넌트.xlsx` | `판매현황`·`재고` 시트가 있음 |
   | 판매 내역 (여러 개 가능) | `20261002_account_newhs_test.xls` | `모델NO`·`주문번호`·`출고일` 머리글 |
   | 재고 | `2026-10-02_stock_list_able.xls` | `상품코드`·`가용수량` 머리글 |
   | 가격세팅 | `261002_가격세팅.xlsx` | `정산가세팅` 시트 |

3. 확인 화면에서 추가될 행, 상품별 가격세팅 매칭을 봅니다. 미등록 상품은 카테고리·모델명을 적고 '포함'을 켜면 들어갑니다.
4. **최신화한 엑셀 만들기** → 내려받기. 파일명 앞 6자리는 **기준일**(오늘의 1영업일 전, 주말·공휴일·대체공휴일 제외)로 바뀝니다. 예: 10/6에 뽑으면 10/5 대체공휴일을 건너뛰어 `261002_…`. 기준일은 화면에서 바꿀 수 있습니다. 원본은 그대로입니다.

가격세팅을 넣으면 맨 위 **재고 현황** 카드에 가격세팅 제품 순서대로 단품·부품·창고별 가용재고가 바로 나옵니다.

## 무엇이 바뀌나

| 시트 | 변경 |
|---|---|
| `판매현황` | 새 판매행을 끝에 추가. 이미 있는 **주문번호**는 건너뜀(같은 파일을 두 번 넣어도 안전). 1행 SUBTOTAL·필터 범위 확장 |
| 월 시트(`YYMM`) | 이번 달 시트가 없으면 직전 달 시트를 복제해 만듦(날짜 1~말일, 총계는 해당 월, 전월 열은 직전 달 수식). 있으면 데이터가 있는 마지막 날까지 `=0`인 날짜 칸을 SUMIFS로 채우고 총계 끝 날짜를 그날로. 원가(AU)는 가격세팅과 모델명이 같은 상품 전부 맞춤 |
| `재고` | 재고 파일로 통째 교체(창고명·창고코드 열은 빼고 기존 열 순서대로). `재고!$B$3:$B$N` 같은 고정 범위를 새 끝 행까지 늘림 |
| 최신 월 시트 AX열 | 머리글 '정산가', 상품마다 가격세팅 **정산가**(G마켓 기준 표, 원 단위 반올림). 가격세팅에 없는 상품은 `-` |
| `일별` | 기준일과 그 전 영업일 두 블록(최신이 위). 그날 판매가 있는 사이트만 판매금액 큰 순으로 열을 두고, 상품코드·출고일·사이트 SUMIFS와 요약 SUM 수식을 넣음. 판매 없는 날은 요약 3줄 |

새 행 값:

- `정산` = 가격세팅 **판매사이트별 정산액** × 수량 — 지마켓·옥션→G마켓·옥션, 하이마트→하이마트, N페이·네이버삽N→스마트스토어, 쿠팡, 컴퓨존, 자사몰. 블록이 없는 사이트(알리 등)는 G마켓 기준 정산가.
- `원가` = 가격세팅 원가(매칭이 없으면 같은 코드의 이전 판매행 원가).
- `카테고리`·`모델명` = 같은 코드의 이전 판매행 → 없으면 월 시트 상품 목록.
- `년월` = `YYMM`, `주` = `26Q4W1` 형식(분기 첫날이 속한 월요일 시작 주가 W1).

가격세팅 모델명과 판매현황 모델명은 표기가 달라서(`지포스`/`GeForce`, `Triple Fan`/`TF`) 표기 차이만 지운 **토큰 집합이 정확히 같을 때만** 잇습니다. 부분 일치는 쓰지 않습니다. 안 맞으면 표에서 직접 고르고, 고른 값은 이 브라우저에 기억됩니다(판매 데이터는 저장하지 않음).

## 가격세팅 검사

가격세팅 파일을 넣으면 **가격세팅 검사** 카드가 뜬다. 오류(빨강)·주의(노랑)·정보(회색) 칩을 눌러 숨기거나 보일 수 있고, '검사 결과 복사'로 글로 복사할 수 있다.

| 분류 | 잡는 것 |
|---|---|
| 엑셀 오류 | `#DIV/0!`·`#REF!` 같은 오류값, 순환 참조, **저장된 값이 수식 결과와 다른 셀**(입력값을 바꾸고 재계산이 안 됐거나 값을 덮어쓴 것 — 원인 셀만 보고하고 연쇄로 달라진 셀은 개수로), 같은 열의 다른 행과 다른 수식, 수식 열에 직접 들어간 값 |
| 입력 누락 | 입력가·원가 빈 값, 기준이 '노출가'/'최대혜택가'가 아님, 같은 상품 중복 |
| 가격 오류 | 입력가 ≠ 기준 가격(노출가/최대혜택가), 등재가 ≥ 노출가 ≥ 2차혜택가 ≥ 최대혜택가 순서 깨짐, 10원 단위 아님 |
| 마진 | 원가 > 입력가, 마진 음수, 마진율 5% 미만(주의), 100% 초과(정보), 마켓 정산액 < 원가 |
| 정산 불일치 | 마켓별 정산액이 기준 정산가와 50원 넘게 차이, 마켓 등재가 빈 값, 프로모션 정산예상금액 ≠ 정산액 |
| 시트 간 불일치 | 마켓별상품코드·최저가비교·G마켓_프로모션의 원가·정산가·등재가·노출가가 정산가세팅과 다름, 표마다 다른 원가, 어느 시트에만 있는 상품 |
| 상품코드 | 지마켓·옥션·자사몰·하이마트·스마트스토어 코드 빈 값(주의), 형식 이상, 중복 코드, 프로모션 시트 코드와 불일치 (쿠팡·컴퓨존은 정보) |
| 수수료·쿠폰 설정 | 비율이 0~1 밖, 음수 한도, 프로모션 시트의 쿠폰율·수수료·카드한도 상수가 정산가세팅 파라미터와 다름 |
| 다나와 최저가 | 손실·보류 판정, 인상 제안, 다나와 최저가보다 비쌈, 수집일이 기준일보다 오래됨, 다나와 코드 미등록 |
| 매출현황 대조 (매출현황을 같이 넣었을 때) | 월 시트·판매이력에서 코드를 못 찾음, 원가 변경(20% 넘으면 주의), 최대혜택가보다 싸게 팔린 건(최근 7일 3%↑ 또는 30일 15%↑), 정산 단가가 마지막 판매행과 다름 |

업무 규칙은 엑셀에 저장된 값(사용자가 본 값)으로 검사하고, 수식 재계산은 `src/formula.js`의 작은 수식 계산기로 한다(IF·MIN·ROUNDDOWN 등; 모르는 함수는 비교를 건너뛴다). 실제 파일의 수식 1,917개가 엑셀 저장값과 모두 일치했고, 일부러 10가지 오류를 심은 사본에서 전부 잡히는 것을 확인했다.

## 검증

0921 → 0922 수작업 파일로 재현 검증: 0921에 9/22 판매 5건을 넣은 결과가 0922와 판매현황 새 행·일별 시트·2609 날짜 칸까지 셀 단위로 같았다(정산·원가는 그날 가격세팅, 재고 범위는 그날 재고 파일에 따라 달라짐).

## 바뀐 ERP 코드

ERP는 같은 상품을 자재 코드(`WD05-1072`, 상품명 `DESK RAM … #`)와 완성품 코드(`BL.9BWWA.420`, `RAM …`)로 나눠 들고 있고, 출고 코드가 바뀌거나 코드에 점이 붙기도 한다(`BL9BWWR.130` → `BL.9BWWR.130`). 월 시트·일별 SUMIFS는 코드 글자가 같아야 세므로 그대로 넣으면 수량·재고가 빠진다.

`src/codes.js`가 아래 중 하나가 맞고 대상 월 시트 행이 하나뿐일 때 같은 상품으로 본다.

1. 코드에서 점·공백만 다름
2. 과거 월 시트에서 같은 모델명으로 쓰인 코드
3. ERP 상품명이 같음(`DESK`·`RAM`·`SSD`·`VGA` 머리말과 `#`만 다름)

- 판매: 판매현황 A열에 **월 시트 AP 코드로 바꿔** 넣는다(월 시트 부품(AQ) 코드로 팔린 것도 AP로). 바꾼 내역은 확인 화면과 결과 보고에 나온다.
- 재고: 월 시트 AR(단품 재고) 수식에 같은 상품의 다른 코드 SUMIF를 더한다. 재고 현황 카드도 같은 규칙으로 센다.

## 지켜야 할 것

- 공휴일 목록은 `src/core.js`의 `HOLIDAYS`(2026~2028). 해마다 확인해서 늘립니다.
- 워크북은 XML을 직접 고칩니다. 서식·이미지·메모·표가 그대로 남습니다. 열 때 Excel이 전체 재계산합니다.
- `판매현황` A~U 머리글이 예상과 다르면 쓰지 않고 멈춥니다.
- 월 시트 상품 목록(AP·AQ 코드)에 없는 상품은 판매현황에는 들어가지만 월 시트 합계에는 안 잡힙니다. 화면 경고로 알려 줍니다.

## 개발

```bash
npm install
npm test
```

실제 파일로 통합 시험을 하려면 **레포 밖** 폴더를 지정합니다.

```bash
SRU_FIXTURES="C:/Users/user/Downloads/261001_매출현황_컴포넌트" npm test
```

명령줄 실행기(웹과 같은 `src/core.js` 사용, 결과는 레포 밖에만 씀):

```bash
node tools/run.mjs --out "C:/Users/user/Downloads/out.xlsx" <파일...>
```

`git config core.hooksPath .githooks`로 훅을 켜 두세요. 데이터 파일이 스테이징되면 커밋이 거부됩니다.
